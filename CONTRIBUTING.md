# Contributing

This workspace supports project teams and collaborators authorized by the relevant Lebanese Red Cross project owner.

1. Read the relevant repository README, security guidance and project-specific contribution rules before making a change.
2. Use an issue or approved internal work item to agree the scope and acceptance criteria; do not disclose sensitive details in public issue trackers.
3. Work in a focused branch and open a pull request. Follow configured branch protection, independent review and deployment requirements.
4. State the change, tests performed, data and privacy impact, migration requirements and rollback plan when appropriate.
5. Use synthetic or appropriately de-identified examples, and seek project/data-owner approval before publishing any code, screenshots, research outputs or datasets.

Do not publish or license software, use the protected Lebanese Red Cross emblem, or assert institutional endorsement without the appropriate approval. Individual repository procedures take precedence over this generic guidance.
