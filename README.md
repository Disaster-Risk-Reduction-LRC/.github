# Lebanese Red Cross DRR — GitHub Workspace

This is the public **`.github` configuration repository** for the Lebanese Red Cross Disaster Risk Reduction (LRC DRR) team's technical workspace.

The organization's public-facing introduction is at [profile/README.md](profile/README.md). Additional files in this repository provide general community guidance to organization repositories that do not override them with project-specific guidance.

## Files

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | Public organization homepage |
| [SECURITY.md](SECURITY.md) | Confidential vulnerability reporting and humanitarian-data safeguards |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Responsible collaboration and review |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Respectful, inclusive collaboration |
| [SUPPORT.md](SUPPORT.md) | Appropriate routes for technical support |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default review checklist |

**Scope:** These materials are repository-level guidance. They do not replace approved Lebanese Red Cross institutional policies, authorize publication of confidential materials, or grant permission to use the protected Red Cross emblem.

The organization avatar is managed separately through [GitHub organization settings](https://github.com/organizations/Disaster-Risk-Reduction-LRC/settings/profile) and should use an LRC-approved logo.
