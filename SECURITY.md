# Security and responsible disclosure

**Confidential reports only.** Do not report suspected vulnerabilities in a public issue or discussion. Use GitHub private vulnerability reporting for an affected repository if enabled, or contact the repository maintainers through an approved private Lebanese Red Cross channel.

Do not share credential values, exploits, production exports, personally identifiable information, volunteer or beneficiary records, or precise protection-sensitive locations in issues, pull requests, logs or screenshots. Use synthetic data to demonstrate a problem.

If sensitive information is exposed, escalate promptly to the relevant LRC system and data owners for assessment, containment, access revocation or credential rotation. Removing a leaked value from the latest commit is not sufficient to remove it from Git history.

Public disclosure, support windows and incident-response times require the respective project's responsible owner's approval. This file does not establish a security service-level agreement.
