# Getting support

For technical questions about a specific project, read its README and use the project team's approved issue tracker or internal support channel. Include expected behaviour, actual behaviour, non-sensitive reproduction steps and relevant screenshots with synthetic data.

Report security vulnerabilities privately following [SECURITY.md](SECURITY.md). Do not share personal, sensitive site or operational response records in GitHub issues.

For official organizational information visit https://www.redcross.org.lb/. This GitHub organization does not provide emergency or public assistance services.
