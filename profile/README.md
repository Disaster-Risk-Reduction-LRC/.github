## About this GitHub organization

This is the technical GitHub workspace for work associated with the **Disaster Risk Reduction (DRR) Unit of the Lebanese Red Cross (LRC)**. It supports collaborative engineering, documentation, geospatial analysis and digital solutions designed to improve risk-informed humanitarian action.

The workspace represents **LRC DRR technical projects**, rather than every programme or technology system operated by the Lebanese Red Cross.

## Areas of work

| Focus | How digital tools support the work |
| --- | --- |
| **Community resilience** | Electronic vulnerability and capacity assessments (eVCA), community planning and risk reduction tools. |
| **Geospatial information** | GIS, climate and multi-hazard data, risk profiles, visualization and decision support. |
| **Preparedness and anticipatory action** | Risk communication, early-action workflows, planning and information sharing. |
| **Humanitarian response** | Structured coordination, assessment data and operational information workflows. |
| **Connected digital systems** | Responsible integration of tools, records, reporting and internal services. |

## Our approach

We build and maintain tools that support **humanity, impartiality, neutrality, independence, voluntary service, unity and universality**, the Fundamental Principles of the International Red Cross and Red Crescent Movement.

In practice, this means user-centred design, reliable data, inclusive access, responsible security and safeguarding, and partnership with the teams that use the tools in the field.

## Repositories and access

Some repositories are private because their code, configuration or operating context requires restricted access. A private repository is **not** a public service, an invitation to contribute, or authorization to publish operational information. Where sharing is approved, project-specific documentation provides appropriate guidance.

Please do not post credentials, personal information, beneficiary or volunteer records, precise protection-sensitive locations, or vulnerability details in public issues or discussions.

## Connect

For official information about the Lebanese Red Cross, visit **[redcross.org.lb](https://www.redcross.org.lb/)**. This GitHub organization is for technical collaboration and is **not** an emergency assistance or incident-reporting channel.
